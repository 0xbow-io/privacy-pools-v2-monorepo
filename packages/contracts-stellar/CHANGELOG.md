# Changelog

All notable changes to the `packages/contracts-stellar` Cargo workspace are documented in this file.

## 1.0.0 — 2026-10-19

Initial release.

- Vendored copy of the Privacy Pools V2 Soroban contracts (`pool`, `keystore`, `asp-registry`, `relay`, the `yield-*` crates, `soroban-v2-utils` and `types`), synced from `0xbow-io/ppv2-stellar` with its tests and deploy tooling.
- The Cargo workspace crate version stays `0.1.0` in this release; `1.0.0` here is the monorepo release version.
